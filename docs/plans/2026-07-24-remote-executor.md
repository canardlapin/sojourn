# sojourn: kernel → real backend-neutral remote executor (exemplary Slurm backend)

## Context

sojourn today is a well-tested kernel (~1.2k LOC): pure SPI types (`Site`, `SiteStore`, `TaskRunner`, `LeasedPool`, `LeaseState`, total `TaskOutcome`) plus the spool v1 wire protocol — no effectful implementation. Goal: make it a **real remote executor** — backend-neutral SPI, a scheduler-free local backend + published conformance kit (TCK) proving the neutrality, and an exemplary Slurm backend composed from `../scala-slurm`. Master plan of record: `../scala-slurm/docs/plans/2026-07-23-site-layer.md` (phases 3b–3e execute in sojourn). Tracker: mote store in `../scala-slurm/.mote`.

**User decisions (2026-07-24):** keep borrowing scala-slurm-core vocabulary (extraction = separate pre-1.0 phase); ship local backend + TCK; scope is cross-repo — beads P6f.23/25/26/27 execute as part of this program.

**Verified state:** scala-slurm has ~124 uncommitted files implementing closed beads P6f.17 (facades), P6f.21 (JobTiming), P6f.22 (Requeued/InterruptionClass), P6f.24 (epoch-fenced retrySubmission) — must be committed & republished first. Confirmed gaps: no AtomicFiles/claim (P6f.26), no SubmissionKey.derive/byKeyPrefix (P6f.25), no SignalSpec/terminationNotice (P6f.23), agent protocol rejects RegisteredTask + has no file put/fetch (P6f.27, itself blocked by open p0 beads P6f.3/4/5/6/9) → **v1 store must be shared-FS; `overSsh` is a follow-on**. No worker/pilot main binary exists anywhere — sojourn ships it. `ContentDigest` is stringly (`algo:hex` shape-parse folds into a core-reopen phase). House style: java.nio in `Async[F].blocking` (never fs2 `Files[F]`), `Vector[Byte]`, deterministic-Instant tests, canonical sorted-key JSON + golden byte fixtures, sealed-ADT failures, `F[_]: Async` + `Resource` lifecycles.

### TCK laws (the conformance contract)

1 catalog honesty; 2 key idempotency + Conflict; 3 total outcomes (no escaping exceptions; Unknown carries diagnostics); 4 Succeeded ⇒ store-fetchable + digest-verified; 5 store put/resolve/fetch laws, corruption ⇒ DigestMismatch, absent ⇒ NotFound; 6 monotone freshness-stamped status; 7 pool lifecycle (acquire completes on **durably-accepted provisioning**; readiness via `Granted` + `awaitGranted`; release drains→settles→cancels; `onRevoked` exactly once) — **this amends master-plan 3d's "acquire awaits ≥min registration"; record the amendment in the ADR + on the bead**; 8 batch/pool parity (same result digest or same outcome class — parity is at TaskOutcome level; batch uses scala-slurm ResultEnvelope, pool uses spool SpoolResult; the TCK compares outcomes, not envelope bytes).

## Spool protocol v1-rev2 + runtime semantics (designed; full spec becomes sojourn ADR-0002 in Phase 5)

**Identity:** `keyToken = hex(sha256(utf8 key))[:32]` is a *locator*, never identity — full key+epoch in every body; readers verify body-vs-filename (`BindingMismatch` typed). Filenames: `<keyToken>-e<epoch>.inv` / `.result` — epoch-in-filename makes races per-epoch; `AttemptEpoch` (dispatcher-exclusive advance) is the fence. One claim at a time per pilot (v1).

**Layout deltas:** + `pool.manifest` (PoolManifest: config, limits; publish-once by dispatcher pre-submission), + `done/<pilot>/` (released-after-publish evidence), + `reclaimed/<pilot>/` + `reclaimed/_pool/` (tombstones), drain.marker gains a `SpoolDrain` body (monotone; never removed; new pool = new root).

**Wire deltas (all canonical + golden-fixtured):** `SpoolInvocation` += attemptId, attemptEpoch, retrySafety, limits, publishedAt(evidence-only). NEW `SpoolResult`: key/attemptId/epoch/op/schema/pilot/release/retrySafety/timestamps + status `succeeded{path,digest}` (store-ref ALWAYS — pilot does store.put first) | `failed{code,message}` | `interrupted{reason: drain-signal|drain-marker|deadline}`. `PilotHeartbeat` += monotone `sequence` (clock-free staleness), `state{starting|ready|busy|draining}`; `claimed` becomes `{key, epoch}`. `PilotRegistration` += optional opaque `allocation`.

**Pilot protocol:** claim (AtomicFiles.claim; losers move on) → verify body+input digest → execute → **publish result FIRST** (FileResultPublisher idiom: temp CREATE_NEW + fsync + ATOMIC_MOVE; `AlreadyPublished` typed non-fatal) → release claim to `done/` SECOND. Invariant P1: `done/` ⇒ result exists.

**Reclaim (dispatcher-exclusive) — evidence ladder:** E1 scheduler-observed terminal → reclaim now. E3 heartbeat-stale but scheduler says Running → NO reclaim, only `Degraded` (+ optional backend cancel converts to E1). E4 scheduler unobservable ∧ stale ∧ past `registration.deadline + drainGrace + δ` (skew budget, default 60s) → reclaim. Procedure: rename to `reclaimed/<p>/` (R1); **re-check results after winning** (R2 — voids reclaim, settles from envelope); else RetrySafety gate (R3): `SafeForAutomaticRetry` + budget (default maxAutomaticRetries=1) → publish `pending/…-e{n+1}.inv`, handle back to Queued; else quarantine → handle settles **Interrupted** (E1 evidence, with `side-effects-indeterminate` diagnostic) or **Unknown** (E4 — deadline-inferred, never observed). Epoch fence P2: only current-epoch results settle; stale results = `superseded` evidence. At-least-once iff declared safe; at-most-once otherwise. Manual retry = `retry(key, expectedEpoch, Manual)` mints new epoch + NEW handle.

**Heartbeat:** atomic whole-file replace (not append); cadence `heartbeatEvery` + on state change. Staleness clock-free: dispatcher tracks (lastSequence, firstSeenAt on OWN clock); stale ⇔ no sequence advance within `k·heartbeatEvery + pollEvery`, **k=3**. Cross-machine instants only in E4/expiry rules, always with δ. Ready ⇔ registered ∧ non-stale ∧ state∈{ready,busy} ∧ no terminal observation. Drops → `Degraded`; recovery re-emits `Granted`; `Lost` = all pilots E1-dead (or spool root gone) without drain.

**Drain:** dispatcher-only writes marker (CREATE_NEW, idempotent, monotone). Pilot stops claiming at earliest of: marker seen / own `deadline − drainGrace` (pilot-local clocks, no skew issue) / P6f.23 pre-deadline signal → cancel task fiber cooperatively, publish `interrupted(drain-signal)` envelope, release, exit 0. Hard walltime kill needs nothing special — reclaim IS the handler.

**Lease machine:** ACQUIRING →(ready≥minReady)→ GRANTED ⇄ DEGRADED; `Renewing` on stale deadline source; terminal `Revoked{Cancelled|Expired|Lost}` exactly once, `events` completes, `onRevoked` completes in the same transition. Pool deadline = minReady-th largest per-pilot observed deadline; revised in either direction by fresher `Current` observations. `readyTimeout` miss → `Lost` with `min-ready-timeout` diagnostics. Release finalizer: marker → await quiesce (bounded) → settle all open handles → cancel array (typed outcome recorded) → Revoked(Cancelled) → retain spool root as evidence.

**Await path:** one scan fiber per pool (`follow`-style poll, default 1s): targeted result-file checks per unsettled handle (deterministic names — no hot-path listing) + one readdir for phases/reclaim + heartbeat reads. Status: Queued=pending, Dispatched=claimed, Running=claimed ∧ fresh heartbeat claims {key,epoch}, Settled=verified result/administrative. Scan IO failure → freshness `Unknown`, handles never settle on read failure; at revocation unsettleable handles → `Unknown(diagnostics)`.

Eleven invariants each pinned to a POSIX primitive (rename exclusivity, CREATE_NEW publish-once, body-verification, monotone sequence, startup atomic-rename probe — typed `AtomicMoveUnavailable`, never copy/delete fallback); 13 race scenarios specified (pilot-dies-between-publish-and-release → R2 voids reclaim; slow-but-alive vs reclaimer → E3 forbids, epoch fence makes wrongful reclaim deterministic; both epochs succeed → fence admits current only; dispatcher crash mid-reclaim → tombstone + idempotent CREATE_NEW re-run).
